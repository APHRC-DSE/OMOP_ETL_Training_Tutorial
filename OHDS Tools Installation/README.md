# OHDSI OMOP Tools Installation Guide

The OHDSI (Observational Health Data Sciences and Informatics) organization provides a suite of open-source tools to 
support the standardization, analysis, and sharing of observational health data. This training manual focuses on 
six key tools within the OHDSI toolkit: Java, White Rabbit, Rabbit in a Hat, Usagi/Athena, R/RStudio, and PostgreSQL.
